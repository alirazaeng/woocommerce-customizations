# Code of Conduct

## Our standard

This project welcomes respectful, technically constructive participation from people of all backgrounds and experience levels.

Contributors are expected to:

- communicate professionally and assume good intent
- focus criticism on code, behavior, documentation, and reproducible evidence
- respect privacy, security, accessibility, and user safety
- avoid harassment, discrimination, threats, personal attacks, or deliberately disruptive behavior
- avoid publishing credentials, private client information, customer data, or other sensitive material

## Technical discussion

Disagreement is welcome when it improves the project. Keep reviews specific, explain trade-offs, and provide reproduction steps, tests, benchmarks, or references when they materially help the discussion.

Maintainers may close or moderate discussions that become abusive, repeatedly off-topic, misleading, unsafe, or unrelated to the repository.

## Scope

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other project spaces managed by this repository.

# WooCommerce Customizations

Production-oriented WooCommerce customization patterns covering products, cart, checkout, customer accounts, orders, and conditional frontend assets.

This repository is being built as a modular portfolio project rather than a collection of unsafe copy-paste snippets.

## Principles

- prefer public WordPress and WooCommerce APIs
- sanitize input and escape output
- avoid direct database manipulation when CRUD APIs exist
- document classic-checkout vs block-based compatibility
- keep examples configurable and safe by default
- regression-test cart, checkout, account, and order flows
- never include client credentials, private data, or proprietary extension code
